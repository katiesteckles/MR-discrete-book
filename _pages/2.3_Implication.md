# Implication connectives

In addition to the three basic logical connectives $\texttt{AND}$, $\texttt{OR}$ and $\texttt{NOT}$, there are two implication connectives: **conditional** and **biconditional**. These correspond to the English language constructions 'if... then' and 'if and only if'.

## Conditionals

```{admonition} Definition 2.6 - The conditional
:label: conditional-definition

Let $p$ and $q$ be propositions. The **conditional**, stated 'if $p$ then $q$', is denoted $p \Rightarrow q$ (or sometimes $p \rightarrow q$). The conditional is true when the values of $p$ and $q$ are consistent with this relationship - that whenever $p$ is true, $q$ is true.

The truth table for $p \Rightarrow q$ is given by

<table style="width:50%">
   <tr><th align="center">p</th><th align="center">q</th><th align="center">p &8658; q</th></tr>
   <tr>
      <td align="center">T</td>
      <td align="center">T</td>
      <td align="center">T</td>
   </tr>
   <tr>
      <td align="center">T</td>
      <td align="center">F</td>
      <td align="center">F</td>
   </tr>
      <tr>
      <td align="center">F</td>
      <td align="center">T</td>
      <td align="center">T</td>
   </tr>
    <tr>
      <td align="center">F</td>
      <td align="center">F</td>
      <td align="center">T</td>
   </tr>
</table>

Note that if $p$ is false, this one-way conditional is true regardless of the truth value of $q$.

In the statement $p \Rightarrow q$, $p$ is sometimes called the **hypothesis** (or **antecedent**, or **premise**)
and $q$ is called the **conclusion** (or **consequence**).

```

For example, let $p$ and $q$ represent the following propositions: $p$ = 'The demand rises' and $q$ = 'The companies expand'. Then $p \Rightarrow q$ can be stated as ‘If demand rises, then companies expand’.

```{admonition} Note
:class: important

The following phrases are all ways to state $p \Rightarrow q$:

- if $p$, then $q$
- $p$ implies $q$
- $q$ follows from $p$
- not $p$ unless $q$
- $q$ if $p$
- whenever $p$, $q$; $q$ whenever $p$
- $p$ is sufficient (or a sufficient condition) for $q$
- $p$ only if $q$
- $q$ is necessary (or a necessary condition) for $p$
```

````{admonition} Example 2.7
```{dropdown} Solution

```
````

## Biconditionals

```{admonition} Definition 2.9 - The Biconditional
:label: biconditional-definition

The **biconditional**, stated '$p$ if and only if $q$', is denoted $p \Leftrightarrow q$ (or sometimes $p \leftrightarrow q$, or $p \textrm{ iff } q$). We say that $p$ and $q$ are **equivalent**. The biconditional is true whenever the truth values of $p$ and $q$ are the same.

The truth table for $p \Leftrightarrow q$ is given by

<table style="width:50%">
   <tr><th align="center">p</th><th align="center">q</th><th align="center">p &8660; q</th></tr>
   <tr>
      <td align="center">T</td>
      <td align="center">T</td>
      <td align="center">T</td>
   </tr>
   <tr>
      <td align="center">T</td>
      <td align="center">F</td>
      <td align="center">F</td>
   </tr>
      <tr>
      <td align="center">F</td>
      <td align="center">T</td>
      <td align="center">F</td>
   </tr>
    <tr>
      <td align="center">F</td>
      <td align="center">F</td>
      <td align="center">T</td>
   </tr>
</table>

```

For example, let $p$ and $q$ represent the propositions, $p =$'$x$ is even' and $q =$'$x$ is divisible by 2'. Then, then $p\Leftrightarrow q$ translates as ‘$x$ is even if and only if $x$ is divisible by 2’.
 
```{admonition} Note
:class: important

The following are all ways to state $p \Leftrightarrow q$:

- $p$ if and only if $q$
- $p$ is equivalent to $q$
- $p$ implies $q$ and $q$ implies $p$
- $p$ is true exactly when $q$ is true
- $p$ and $q$ have the same truth table
- For $p$ to be true, it is necessary and sufficient for $q$ to be true.

```

```{admonition} Note
:class: important

The binary connective $\Leftrightarrow$ is symmetric, but $\Rightarrow$ is not, in that the changing the order of the propositions will give a different statement (in this case, the converse).

```

The precedence rules for logical connectives also apply to implication connectives:

- The $\Rightarrow$ operator takes precedence over $\Leftrightarrow$, and both are lower precedence than $\land$ and $\lor$. 

Thus, $p \Rightarrow q \lor r$ means $p \Rightarrow (q \lor r)$, not $(p \Rightarrow q) \lor r$.

Similarly, $p \Leftrightarrow p\Rightarrow q$ can be understood as $p \Leftrightarrow (p \Rightarrow q$), since $\Leftrightarrow$ has the lowest precedence.

As always, brackets can be used to resolve any ambiguity.

# Tautology and Contradiction

There are some compound propositions for which every possible combination of truth values for the component propositions results the same overall truth value. We have specific names for these, in the cases where they will always be true or always be false.


```{admonition} Definition 2.10 - Tautology
:label: tautology-definition

A **tautology**, often denoted $\top$ or $T$, is a compound proposition that is true for all possible interpretations (truth values) of its component propositions.

```

For example, the proposition $p \lor \not p$ ('p or not p') is a tautology. Indeed, the truth table for $p \lor \not p$ is given by

   </tr>
   <tr>

      <td align="center">T</td>
   </tr>
</table>

```{admonition} Definition 2.12 - Contingency
:label: contingency-definition

A compound proposition that is neither a tautology nor a contradiction is called a
**contingency** proposition.

```

A contingency is neither always true nor always false; there must exist at least one universe of possibilities in which it is true, and one in which it is false.
