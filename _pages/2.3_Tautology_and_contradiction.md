contingency proposition.

2.5. Argument
An argument is represented by a compound proposition in which the premises together
logically imply the conclusion. Thus if 𝑝1, 𝑝2, … , 𝑝𝑛 denote the premises and q denotes
the conclusion, then an argument can be written as
(𝑝1 ∧ 𝑝2 ∧ 𝑝3 ∧ … ∧ 𝑝𝑛)  q
An alternative notation for this argument is
𝑝1, 𝑝2, 𝑝3, … , 𝑝𝑛 ⊨ q
• If the hypothesis is true and the conclusion is also true, then the argument is
true.
• If the argument is true it is said to be a valid (or a sound) argument.
• If an argument is false, then it is said to be a fallacy.
