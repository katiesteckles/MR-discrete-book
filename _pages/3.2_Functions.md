3.1.2 Functions
All functions are relations, but not all relations are functions.
How to convert a Relation into a function?
A function is a special kind of relation (a set of ordered pairs) which follows a rule
i.e. every x -value should be associated with only one y-value is called a Function.
Definition of Function:
• A relation is a correspondence between two variables.
• A relation can be expressed through a set of ordered pairs, a graph, a table, or an
equation.
• A set containing ordered pairs (x, y) defines y as a function of x if and only if no
two ordered pairs in the set have the same x-coordinate. In other words, every
input map to exactly one output.
• A function is a rule that assigns each input exactly one output.
We call:
• the output the image of the input.
• The set of all inputs for a function is called the domain.
• The set of all allowable outputs is called the codomain.

Vertical Line Test
The vertical line test is a graphical method of determining whether a curve in
the plane represents the graph of a function by visually examining the number
of intersections of the curve with vertical lines.
The motivation for the vertical line test is as follows: A relation f : A → B is a function
precisely when each element x∈ A is matched to at most one value f(x) ∈ B and, as a
result, any vertical line in the plane can intersect the graph of a function at most once.
Therefore, the vertical line test concludes that a curve in the plane represents the graph of
a function if and only if no vertical line intersects it more than once.
3.1.3 Injections, Surjections and Bijections
We now turn to investigating special properties functions might or might not possess.
3.1.3.1 Definition: Injective or one-to-one Function:
Let f : A → B be a function. We say that f is injective or one-to-one if and only if for all
x, y∈ A; if f(x) = f(y) then x = y.
Using the concept of contrapositive, a function f is injective if and only if for all x, y∈ A,
if x ≠ y then f(x) ≠ f(y).
Taking the negation of this last conditional implication we see that f is not injective if
and only if there exist two distinct elements a and b of A such that f(a) = f(b).

3.1.3.2 Definition: Surjective or onto Function
Now, for any function f : A → B we have Range(f) ⊆ B.
If equality holds then we say that f is surjective or onto.
It follows from this definition that a function f is surjective if and only if for each y∈ B
there is an x ∈ A such that f(x) = y.
i.e if every y ∈ B has a preimage. In this case, the range of f is equal to the codomain
By taking the negation of this we see that f is not onto if there is a y ∈ B such that
f(x) ≠ f( y) for all x ∈ A.
Example:
(a) Show that the function f : ℝ → ℝ defined by f(x) = 2x+3 is surjective.
(b) Show that the function f : ℤ → ℤ defined by f(n) = 2n+3 is not surjective.
Solution:
(a) Let y ∈ R. Is there an x ∈ ℝ such that f(x) = y? That is, 2x+3 = y.
But solving for x we find x = (y+3)/2∈ ℝ and f(x) = y. Thus, f is onto.
(b) Take m =4. If f is onto then there should be an n ∈ ℤ such that f(n) = 4.
That is, 2n+3 = 4: Solving for n we find n = 1/2 which is not an integer.
Hence, f is not onto.
