2.11.2 Quantifying Predicates
Quantifiers indicate how frequently a certain statement is true. When the variable say x
of a predicate 𝑃(𝑥) is replaced by some element belonging to a set say A, the resulting
proposition is either true or false. Sometimes the logical value of a predicate is true (or
false) for all x or some x belonging to a set A.
The phrases ‘for all x’ , ‘for each x’ and ‘for any x’ are referred to as the universal
quantifier and the phrases ‘for some x’, there exists an element x’ and ‘there are x and
y’ are referred to as the existential quantifier. The set A is called the scope of the
quantifier. The variable x is said to be bound by the quantifier.
In symbolic form when using the universal quantifier we write x A , which is read as
‘for all x belonging to A’. The symbol  is read ‘for all’.
Similarly, when using the existential quantifier we write x A, which is read as ‘for
some x belonging to A’. The symbol  is read ‘for some’ or ‘there exists’. For the
existential quantifier other expressions such as ‘there exists an x such that’ and ‘there
exists at least one x such that’ are also used.
