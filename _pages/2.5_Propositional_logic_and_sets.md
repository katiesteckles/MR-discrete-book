# Propositional Logic and Sets


2.8 Relation between Sets and Logic:
If we look to section 1.10 (chapter 1) which describes the Laws of Set Algebra and
section 2.7 (chapter 2) which describes Algebraic Laws with propositional Logics we
could find that these laws are remarkably similar.
In fact, simply making the following mechanical changes:
• From A, B, C to P, Q, R
• From ∩ to 
• From ∪ to 
• From c or ‘ to 
• From = to 
• From U to T
• From 𝜑 to F
Translate any related expression from Set theory into logical expression (and vice versa).
Example18
Convert these set theory expressions / equalities to logical notation, using logical
variables P, Q, and R.
1. (𝐴 ∪ 𝐵) ∩ (𝐶𝑐 ∪ 𝑈)
2. (𝐴 ∩ 𝐵𝑐) ∪ 𝜑 = (𝐴𝑐 ∪ 𝐵𝑐)
Solution:
1. (𝑃 ∨ 𝑄) ∧ (¬𝑅 ∨ 𝑇)
2. (𝑃 ∧ ¬𝑄) ∨ 𝐹 ≡ (¬𝑃 ∨ ¬𝑄)
