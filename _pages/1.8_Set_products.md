# Set Products


So far, in discussing sets, the order of the elements of a set has been irrelevant. Here, we
introduce the concept of ordered sets, where the order in which the elements are listed is
important.

We use the notation $(a,b)$ to indicate an ordered pair of objects $a$ and $b$. This can be thought of as the set of two elements, $\{a,b\}$, together with the condition that $a$ comes before $b$.


```{admonition} Definition 1.9 - Cartesian Product
:label: cartesian-product-definition

Let A and B be any two sets. The **Cartesian product** of $A$ and $B$, denoted $A \times B$, is the set of all ordered pairs such that the first member of the ordered pair is an element of $A$ and the second member is an element of $B$.
$$A \times B = \{(x, y)\ |\ x \in A \textrm{ and } y \in B\}$$

Similarly, the Cartesian product of three sets $A, B$ and $C$ can be expressed as:
$$A \times B \times C = \{(x, y, z)|x \in A, y \in B \textrm{ and }z \in C\}$$

The Cartesian product of $n$ sets $A_1, A_2, A_3, \ldots , A_n$ is the set of all ordered $n$-tuples $(a_1,a_2,a_3,\ldots ,a_n)$, where $a_i \in A_i$ for $i = 1,2,3, \ldots n$ .
$$A_1 \times A_2 \times \ldots \times A_n = \{(a_1, a_2, a_3, \ldots , a_n)\ |\ a_i \in A_i, i = 1,2,3, \ldots n\}$$

```

For example,
- If $A = \{0,1,2\}$ and $B = \{2,3\}$, then the Cartesian product of $A$ and $B$ is given as:
$$A \times B = \{(0,2), (0,3), (1,2), (1,3), (2,2), (2,3)\}$$

- If $A = \{1,2\}$ and $B = \{p, q, r\}$, then the Cartesian product of $A$ and $B$ is given as:
$$A \times B = \{(1, p), (1, q), (1, r), (2, p), (2, q), (2, r)\}$$

- If $A = \{1,2\}, B = \{m, n\}$ and $C = \{p, q\}$, then the Cartesian product of $A, B$ and $C$
is given as:
$$A \times B \times C = \{(1, m, p), (1, m, q), (1, n, p), (1, n, q),$$
$$ (2, m, p), (2, m, q), (2, n, p), (2, n, q)\}$$

## Representation of Cartesian Products

An important example of a Cartesian product is given by the set of Cartesian coordinates in a plane. This product is given as $\mathbb{R} \times \mathbb{R}$, or $\mathbb{R}^2$, and can be visualised as a pair of axes at right-angles to each other in 2D space. The axes themselves represent the two copies of $\mathbb{R}$, and any point in the space can be described using an ordered pair of values, one from the '$x$' copy of the set and one from the '$y$' set.

For sets with finitely many elements, we can represent the Cartesian product using a table. For the product of two sets $A$ and $B$,  The elements of $A$ will be listed in the rows and the elements of $B$ in the columns.

For example, let $A = \{a, b\}$ and $B = \{w, x, y, z\}$. Then $A \times B$ can be represented by:

$$ A \times B = \{(a, w), (a, x), (a, y), (a, z), (b, w), (b, x), (b, y), (b, z)\}$$

```{admonition} Theorem 1.10 - Properties of Cartesian Products
:label: cartesian-product-properties-theorem
:class: attention

- $A \times B \neq B \times A$
The Cartesian product deals with ordered pairs, so the order in which the sets are considered is important.
- $n(A \times B) = n(A) \cdot n(B)$
That is, the number of elements in the Cartesian products of sets can be found my multiplying the cardinalities of the individual sets.
e.g £$(A) = 2, n(B) = 4, n(C) = 1, n(D) = 2$, and $n(A \times B \times C \times D) = 16$


```
