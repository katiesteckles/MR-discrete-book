3.1.4 Combining Real-valued Functions
A lot of the time the functions we encounter in mathematics are real-valued, i.e. functions
whose domain and co-domain are subsets of the real numbers ℝ.
Combining functions means performing basic arithmetic (addition, subtraction,
multiplication, and division) with functions.
Let’s start with basic arithmetic of functions. Given two functions f(x) and g(x) we have
the following notation and operations.
(f + g)(x) = f(x)+g(x)
(f − g)(x) = f(x)−g(x)
(f . g)(x) = f(x)g(x)
(λf) (x) = λ (f(x)), λ∈ R
(1/f) (x) = 1 /f(x) or in general (λ/f) (x) = λ /(f(x)), λ∈ ℝ
(f / g)(x) = f(x)/g(x)
Sometimes we will drop the (x) part and just write the following,
f + g = f(x)+ g(x), f − g = f(x) − g(x), f .g = f(x) g(x), λ.f = λ (f(x)), λ∈ ℝ
(1/f) = 1 /f(x) or in general (λ/f) = λ /(f(x)), λ∈ R and f / g = f(x) / g(x)

3.1.5 Function Composition
Now we need to discuss the new method of combining functions. The new method of
combining functions is called function composition.
Composing functions is the process of applying functions in sequence, one after the
other. You will see it occurring in all areas of mathematics. It is a fundamental
mathematical concept and we can study it even before admitting any notion of number or
measurement etc. It will play an important role in our study of groups in the next chapter.
Definition: Let f : X → Y and g : Y → Z be two functions (note that the co-domain of f is
also the domain of g). Then we can form a new function
g ◦ f : X → Z,
defined by the formula (g ◦ f) (x) = g(f(x)).
We can refer to g ◦ f as g composed with f, or more informally, g after f
Exampgle: Consider the real-valued functions f and g defined by the formulas
f(x)=2+3x-x2 and g(x)=2x-1
Then we can find formulas defining the composition as follow,
(f◦g)(x)=f(g(x))=f(2x-1)=2+3(2x-1)-(2x-1)2=2+6x-3-4x2+4x-1=-4x2+10x-2
(g◦f)(x)=g(f(x))=g(2+3x-x2)=2(2+3x-x2)-1=4+6x-2x2
-1=-2x2+6x+3
Note that these formulas are different. In general, even when both compositions are defined,
composition is not commutative, i.e. f ◦ g ≠ g ◦ f, although in special cases they may be equal.

3.1.5.1 Definition: (Identity function)
The identity function id on the domain X is the function
id : X → X,
defined by the formula
∀ x ∈ X id(x) = x.
We shall speak of the identity function in different contexts without necessarily specifying the
domain. The domain can always be determined from the specific context. The identity function
has the property that when composed with another function, it leaves the other function
unchanged, i.e.
f ◦ id = id ◦ f = f.
Sometimes the effect of a function can be reversed, as in the following definition.
3.1.5.2 Definition: (Inverse function)
Let f : X → Y be a function that is bijective, i.e. is injective and surjective. Then there exists a
function
f -1 : Y → X,
called the inverse of f, which has the property that
f -1 ◦ f = f ◦ f -1 = id.
Or in other words,
∀ x ∈ X f -1(f(x)) = x,
and ∀ y ∈ Y f(f -1(y)) = y.

3.1.5.3 Finding the Inverse of a Function:
Given the function f(x) we want to find the inverse function f -1(x)
1. First, replace f(x) with y.
2. Replace every x with y and replace every y with an x.
3. Solve the equation from step 2 for y (i.e. make y as a subject).
4. Replace y with f -1(x).
You can verify your answer by checking that
(f ◦ f -1 )(x) = x=id(x) and (f -1 ◦ f)(x) = x=id(x)
