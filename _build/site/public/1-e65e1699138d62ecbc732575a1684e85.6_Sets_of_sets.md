1.9 Classes of Sets, Power Sets
1.9.1. Classes of Sets: Sets can be elements of other sets. For example, each line in a set
of lines is a set of points. We usually use the word class or family for such a set.
Example: The members of the class {{2, 3}, {2}, {5, 6}} are the sets {2, 3}, {2}
and {5, 6}.

1.9.3 Partition
A partition of a set A is a subdivision of A into nonempty subsets which are
disjoint and whose union is A, i.e. is a class of nonempty subsets of A such that
each 𝑎 ∈ 𝐴 belongs to a unique subset.
The subsets in a partition are called cells.
