# Set Operations

There are various operations we can perform to compare and combine sets, and observe the relationships between them.

## Unions

```{admonition} Definition 1.10 - Union
:label: set-union-definition

The **union** of two sets $A$ and $B$, denoted  $A \cup B$, is the set of elements that lie in $A$ or $B$ (or both); that is, 
$$A \cup B = \{x\ |\ x \in A \textrm{ or } x \in B\}$$

```

For example, let $A = \{2, 4, 5\}$ and $B = \{1,4,6,8\}$. Then, $A \cup B = \{1, 2, 4, 5, 6, 8\}$. (Recall that each element in a set need only be listed once.)

## Intersections

```{admonition} Definition 1.11 - Intersection
:label: set-intersection-definition

The **intersection** of two sets $A$ and $B$, denoted $A \cap B$, is the set of elements that lie in both $A$ and $B$. That is,
$$A \cap B = \{x\ |\ x \in A \textrm{ and } x \in B\}$$

```


For example,

- Let $A = \{2,4,5\}$ and $B = \{1,4,6,8\}$ Then $A \cap B = \{4\}$.

- Let $A = \{2,4,5\}$ and $B = \{1,3\}$. Then $A \cap B = \varnothing$.


```{admonition} Note
:class: important

If a set contains only a single element, it is sometimes called a **singleton set** or **unit set**.
```

If two sets do not intersect, we say they have an empty intersection, and write $A \cap B = \varnothing$.

## Other ways to combine sets

```{admonition} Definition 1.12 - Symmetric Difference
:label: set-symdiff-definition

The **symmetric difference** of two sets $A$ and $B$, denoted $A \oplus B$, is the set of elements that lie in one of $A$ or $B$ but not in both - that is, $A \oplus B = \{ x\ |\ x \in A \cup B, x \not\in A \cap B \}$. We can write:
$$ A \oplus B = (A \cup B) \setminus (A \cap B) = (A \setminus B) \cup (B \setminus A)$$

```

For example,

- Let $U = \mathbb{N}$ be the universal set, and let $A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6, 7\}$, $C = \{2, 3, 8, 9\}$, and let $E = \{2, 4, 6, 8, \ldots\}$ be the even numbers. Then
$$A \oplus B = \{1, 2, 5, 6, 7\} \qquad B \oplus C = \{2, 4, 5, 6, 7, 8, 9\} \qquad A \oplus C = \{ 1, 4, 8, 9\}$$
And $A \oplus E = \{1, 3, 6, 8, 10, \ldots \}$ 
(this is the infinite set of even numbers, but with $2$ and $4$ replaced by $1$ and $3$).


The operations $\cup, \cap$ and $\setminus$ can be repeated or combined to derive more sets. We can use brackets to specify the order in which operations must be performed.

````{admonition} Example 1.8
:label: set-complements-example
:class: hint

Let $A = \{1,2,3,4\}, B= \{3,4,5,6,7\}$ and $C = \{6,7,8\}$. Write in list form:

(i) $(A \cup B) \cap C$

(ii) $(A \cup C) \setminus (B\cup C)$


```{dropdown} Solution

(i) $(A \cup B) \cap C = \{1,2,3,4,5,6,7\} \cap \{6,7,8\} = \{6,7\}$

(ii) $(A \cup C) \setminus (B\cup C) = \{1,2,3,4,6,7,8\} \setminus \{3,4,5,6,7,8\} = \{1,2\}$
```
````

```{admonition} Definition 1.13 - Disjoint sets
:label: disjoint-union-definition

Two sets $A$ and $B$ are said to be **disjoint** or **non-intersecting** if they have no elements in common - or, using
the definition of intersection, $A$ and $B$ are disjoint if $A \cap B = \varnothing$, the empty set.

If $S = A \cup B$ and $A \cap B = \varnothing$, we say $S$ is the **disjoint union** of $A$ and $B.

```

````{admonition} Theorem 1.5 - Properties of unions and intersections
:label: unions-and-intersections-theorem
:class: attention

For two sets $A$ and $B$, we have:

- Every element $X$ in $A \cap B$ belongs to both $A$ and $B$; hence
$$x \in A \cap B \Rightarrow x \in A \textrm{ and } x \in B$$
- $A \cap B$ is a subset of $A$ and a subset of $B$; that is,
$$A \cap B \subseteq A \qquad A \cap B \subseteq B$$
- Every element $X$ in $A \cup B$ belongs to either $A$ or $B$; hence
$$x \in A \cap B \Rightarrow x \in A \textrm{ or } x \in B$$
- $A$ and $B$ are both subsets of $A \cup B$; that is,
$$A \subseteq A \cup \qquad B \subseteq A \cup B$$

````
