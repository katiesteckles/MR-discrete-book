# Cardinality of sets

The number of elements in a set, or the size of the set, is an important property to study.

```{admonition} Definition 1.7 - Finite and infinite sets
:label: set-equality-definition

A set is **finite** if it is empty, or if it consists of exactly $n$ distinct elements where $n$ is a positive integer; otherwise it is **infinite**.

A set is **countable** if it is finite, or if it has infinitely many elements which can be ordered in a sequence, in which case S is said to be **countably infinite**; otherwise the set is **uncountable**.

```

## Cardinality of finite sets

```{admonition} Definition 1.7 - Set Cardinality
:label: set-cardinality-definition

The **cardinality** of a finite set $A$ is the number of elements that it contains, or the size of the set. The cardinality of $A$ is denoted by $n(A)$ or $|A|$.

```

For example,
- Let $A$ be the set of odd positive integers less than 10. Then $n(A)=|A| = 5$.

- Let $S$ be the set of letters in the English alphabet. Then $n(S)=|S| = 26$.

- Because the empty set has no elements, we have $n(\varnothing) = 0$.

```{admonition} Theorem 1.8 - Inclusion-Exclusion Principle
:label: inclusion-exclusion-theorem
:class: attention

Suppose A and B are finite sets, not necessarily disjoint. Then 𝐴 ∩ 𝐵 and 𝐴 ∪ 𝐵 are
finite, and
𝑛(𝐴 ∪ 𝐵) = 𝑛(𝐴) + 𝑛(𝐵) − 𝑛(𝐴 ∩ 𝐵).

That is, we find the number of elements in A or B (or both) by first adding 𝑛(𝐴) and 𝑛(𝐵)
(inclusion) and then subtracting 𝑛(𝐴 ∩ 𝐵) (exclusion) since the elements in 𝐴 ∩ 𝐵were
counted twice.

Suppose A, B and C are finite sets. Then 𝐴 ∪ 𝐵 ∪ 𝐶 is finite and
𝑛(𝐴 ∪ 𝐵 ∪ 𝐶) = 𝑛(𝐴) + 𝑛(𝐵) + 𝑛(𝐶) − 𝑛(𝐴 ∩ 𝐵) − 𝑛(𝐴 ∩ 𝐶) − 𝑛(𝐵 ∩ 𝐶) + 𝑛(𝐴 ∩ 𝐵 ∩ 𝐶).
```

For example,
Suppose an art class A has 25 students and 10 of them are taking a biology class B. Then
the number of students in class A which are not in class B is:
𝑛(𝐴\𝐵) = 𝑛(𝐴) − 𝑛(𝐴 ∩ 𝐵) = 25 − 10 = 15
