# Predicate Logic


2.10. Predicates
Predicate logic is an extension of propositional logic with more expressive power. It is
needed because the type of argument captured by propositional logic is limited. Many
statements in mathematics are not simply propositions. In many instances there are
statements whose truth depends on the value of a variable that occurs in the statement.
Example 1
i. (10  0) − a proposition, − true.
ii. (x  0) − not a proposition, − the truth value depends upon x.
iii. ‘x is greater than y’, - not a proposition,
− the truth value of this statement depends on the values of x and y.
For some values of x and y (e.g. 𝑥 = 3, 𝑦 = 1 say) the logical value of the expression is
true but for some other values it (e.g. 𝑥 = 1, 𝑦 = 5 say) it is false.
Definition:
A predicate or an open statement is a statement containing a variable (or an argument)
such that when the variable is substituted by an acceptable specific object the statement
becomes a proposition.
A set of all acceptable objects that can be permitted to replace the variable is called the
domain (or the universe of discourse) of the predicate or the replacement set of the
variable(s).
Alternatively, we can define a predicate as being a function, taking arguments (or
parameters) and returning a value true or false.
OR
A predicate P(x) is a statement that incorporates a variable x, such that whenever x is
replaced by a value, the resulting proposition is unambiguously true or false. If the
predicate uses several variables 𝑥1, 𝑥2, 𝑥3, . . . . . . .. then we will extend the notation to
𝑃(𝑥1, 𝑥2, . . . . . . . ) accordingly.
Note that in the literature several other words are used for the word object including
‘subject’, ‘term’ and ‘individual’.
Example 2
Consider the sentence: ‘Manchester and Liverpool are cities’
The descriptive phrase ‘are cities’ is a predicate. The entities connected in this way,
Manchester and Liverpool are the variables.

Example 3
The following statements are all predicates:
i. She arrived yesterday.
‘She’ is not identified, and it is not possible to assign a logical value to this
expression.
ii. A is a number greater than 100.
The subject ‘A’ is not identified and therefore it is not possible to find the logical
value of this expression.
iii. x is a student.
‘x’ is not determined and so this expression also has no logical value.
Note that, the domain is somewhat arbitrary and so should always be clearly specified.
This is similar to the concept of the universal set. Also, it is usual to think only of the
elements of the domain for which the predicate is true but remember that any domain
element can replace the variable, possibly resulting in a predicate which is false.
The predicates are generally denoted by capital letters and the associated variables or the
arguments are denoted by lower case letters listed in parentheses.
Example 4
If P(n) is the predicate “n is even” write the proposition that results when the variable n is
replaced by each of the values 2, 17,and 240. Which of the resulting statements are true?
Solution:
We will write P(2) to denote the proposition resulting from replacing n with 2 in the
predicate P(n). In this case, P(2) is the true proposition “2 is even”. Similarly, P(17)
denotes replacing n by 17, giving us the false statement “17 is even”. Finally, P(240) is
the true statement “240 is even”.

Here P is the predicate, x is the variable and N is the domain.
ii. P(x, y), with x, y  R
This is a predicate with two variables x and y and R is the domain.
