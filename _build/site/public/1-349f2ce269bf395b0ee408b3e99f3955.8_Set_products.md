# Set Products


So far, in discussing sets, the order of the elements of a set has been irrelevant. Here, we
introduce the concept of ordered sets, where the order in which the elements are listed is
important.

We use the notation $(a,b)$ to indicate an ordered pair of objects $a$ and $b$. This can be thought of as the set of two elements, $\{a,b\}$, together with the condition that $a$ comes before $b$.


```{admonition} Definition 1.9 - Cartesian Product
:label: cartesian-product-definition

FROM HERE

Let A and B be any two sets. The set of all ordered pairs such that the first member of the
ordered pair is an element of A and the second member is an element of B, is called the
Cartesian product of A and B written as A \times B (which reads as A cross B), i.e.
$$A \times B = \{(x, y)\ |\ x \in A \textrm{ and } y \in B\}$$
Similarly, the Cartesian product of 3 sets A, B and C can be expressed as:
$$A \times B \times C = \{(x, y, z)|x \in A, y \in B \textrm{ and }z \in C\}$$
For any $n$ sets $A_1, A_2, A_3, \ldots , A_n$ the set of all ordered n-tuples $(a_1,a_2,a_3,\ldots ,a_n)$
where $a_i \in A_i$ for $i = 1,2,3, \ldots n$ is called the Cartesian product of sets $A_1, A_2, A_3, \ldots , A_n$ and is
denoted by
$$A_1 \times A_2 \times \ldots \times A_n = \{(a_1, a_2, a_3, \ldots , a_n)\ |\ a_i \in A_i, i = 1,2,3, \ldots n\}$$

```

There are two things worth noting :
1. A \times B \neq B \times A.
The Cartesian product deals with ordered pairs, so naturally the order in which
the sets are considered is important.
2. n(A \times B) = n(A). n(B).
The number of elements in the Cartesian products of sets can be found using
the corresponding set cardinalities,
i.e. n(A) = 2, n(B) = 4, n(𝐶) = 1, n(𝐷) = 2, and
n(A \times B \times 𝐶 \times 𝐷) = 16.
