# Cardinality of sets

The number of elements in a set, or the size of the set, is an important property to study.

```{admonition} Definition 1.7 - Finite and infinite sets
:label: set-equality-definition

A set is **finite** if it is empty, or if it consists of exactly $n$ distinct elements where $n$ is a positive integer; otherwise it is **infinite**.

A set is **countable** if it is finite, or if it has infinitely many elements which can be ordered in a sequence, in which case S is said to be **countably infinite**; otherwise the set is **uncountable**.

```

## Cardinality of finite sets

```{admonition} Definition 1.7 - Set Cardinality
:label: set-cardinality-definition

The **cardinality** of a finite set $A$ is the number of elements that it contains, or the size of the set. The cardinality of $A$ is denoted by $n(A)$ or $|A|$.

```

For example,
- Let $A$ be the set of odd positive integers less than 10. Then $n(A)=|A| = 5$.

- Let $S$ be the set of letters in the English alphabet. Then $n(S)=|S| = 26$.

- Because the empty set has no elements, we have $n(\varnothing) = 0$.

```{admonition} Theorem 1.7 - Cardinality of combined sets
:label: cardinality-of-combined-sets-theorem
:class: attention

If $A$ and $B$ are finite disjoint sets, then $A \cup B$ is finite and
$$ n(A \cup B) = n(A) + n(B)$$

If $A \subset U$, a finite universal set, then $U$ is the disjoint union of $A$ and its
complement $A^\mathsf{c}$. Then
$$n(U) = n(A) + n(A^\mathsf{c}) \qquad \textrm{ and } \qquad n(A^\mathsf{c}) = n(U) - n(A)$$

If $A$ and $B$ are finite sets, then
$$n(A\setminus B) = n(A) - n(A \cap B)$$

``` 

For example,

- If there are $2$ goth members in a band of $5$ musicians, then there are $5 – 2 = 3$ non-goth band members.

- Suppose an archery class $A$ contains $35$ students, and $15$ of them are also in a bowling class $B$. Then
$$n(A \setminus B) = n(A) - n(A \cap B) = 35 - 15 = 20$$

Determining the cardinality of unions of non-disjoint sets is slightly harder, as the size of the union will depend on to what extent the sets overlap.

````{admonition} Theorem 1.8 - Inclusion-Exclusion Principle
:label: inclusion-exclusion-theorem
:class: attention

Suppose $A$ and $B$ are finite sets, not necessarily disjoint. Then $A \cap B$ and $A \cup B$ are finite, and
$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$

That is, we find the number of elements that are in $A$ or $B$ (or both) by first adding $n(A)$ and $n(B)$ (inclusion), and then subtracting $n(A\cap B)$ (exclusion) - since the elements in $A\cap B$ were counted twice, we need to remove them from the total.
````
