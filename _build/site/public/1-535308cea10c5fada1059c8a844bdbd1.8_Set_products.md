1.11 Cartesian or Cross products
So far, in discussing sets, the order of the elements of a set has been irrelevant. Here, we
introduce the concept of ordered sets, where the order in which the elements are listed is
important.
In Mathematics the notation(𝑎, 𝑏) is used to represent an ordered pair. That is the set of
two elements {𝑎, 𝑏} together with the condition that element ‘a’ is regarded as the first.
