# Sets

```{index} Sets
```

The theory of sets is a hugely important basis for many other areas of mathematics, with a long history. 

```{admonition} Definition 1.1 - Set
:label: set-definition

A **set** is a collection of objects. The objects belonging to a set are called **elements** or **members** of the set. We might define the elements in a set by listing them (sometimes called **tabular form**), or stating a property they all share. A set has no duplicates, and the order of the objects in the set is not important.

$$ S = \{ a, b, c \} \qquad \mathbb{N} = \{ 1,2,3,4 \ldots\} \qquad X = \{ x \in \mathbb{N}: 1 \leq x \leq 10 \} $$


Sets are usually denoted by capital letters and set elements are denoted by lower case letters.
The symbol $\in$ is used to denote ‘is an element of’ or ‘belongs to’ or ‘a member of’.
```

The elements of a set can be written in a list, separated by commas, in between a pair of set brackets: $\{ \}$. (This is sometimes called **roster notation**.)

We need sets to be **well-defined**, which means it should always be possible from the definition of a set to decide whether a given element belongs to the set or not. 

```{admonition} Example 1.1
:label: set-definition-example
:class: hint

Which of the following are well-defined sets?

(i) Let $A$ be the set of all whole numbers greater than $0$

(ii) Let $B$ be the set of all numbers funkier than $8$

(iii) Let $C$ be the set of numbers that are both odd and even.

(iv) Let $D$ be the set of all numbers that are in the set $D$

(iv) Let $E$ be the set of numbers where the sum of the numbers in the set is $10$.

```{dropdown} Solution

(i) This is well-defined.

(ii) This is not well-defined, as funkiness is not a subjective property of numbers that can be evaluated unambiguously.

(iii) This is well-defined, as I can tell you whether any given number belongs in the set not (but the answer is no for all numbers!)

(iv) This is not well-defined, as I cannot say whether a particular number is in the set or not without more information.

(iv) This is not well-defined, as it does not define a unique set.

```


````{admonition} Theorem 1.1 - The Axiom of Extensionality
:label: axiom-of-extension-theorem
:class: attention

Two sets $A$ and $B$ are equal if and only if $A$ and $B$ contain the same elements.

- A set is completely defined by its elements
- The order the elements are listed in the set is irrelevant
- If the same element is listed more than once, the additional instances can be ignored

$$ S = \{ a, b, c \} = \{ a, c, b \} = \{ a, b, b, c, c,c,c,c \}$$

````

## Set-builder notation

We can write a set by specifying the underlying set its elements are drawn from, then giving a condition the elements must meet in order to be included in the set.

$$\textrm{e.g} \qquad X = \{ x \in \mathbb{N}\ |\ 1 \leq x < 6 \} = \{ 1,2,3,4,5\} $$

Here $X$ is the set we are defining, and its elements are drawn from the natural numbers $\mathbb{N}$. In order to be included in this set, a natural number $x$ must satisfy $\leq x < 6$. The number $6$ is not strictly less than itself, so it is not included in the set.

$$ Y = \{ x \in \mathbb{N}\ |\ x = 2k, k \in \mathbb{N} \} = \{ 2, 4, 6, 8, \ldots\} $$

The condition can involve other variables, as long as they are also well-defined.

$$ Z = \{ x \in \mathbb{N}\ |\ x \textrm{ has exactly two prime factors} \} = \{ 4, 6, 9, 10, 14, 15, \ldots\} $$

If the condition cannot easily be expressed using algebra, it can instead be stated in words.


```{admonition} Note
:class: important

When reading this notation aloud, the vertical line | separating the underlying set from the condition can be read as 'such that'. A colon : is sometimes used in place of the vertical line.
```

````{admonition} Example 1.2
:label: set-builder-notation-example
:class: hint

Write the following as an expression in set-builder notation.

(i) Let $P$ be the set of all positive integers between $2$ and $16$ inclusive.

(ii) Let $Q$ be the set of all positive integers that are divisible by 3.

(iii) Let $R$ be the set of all positive even integers.

(iv) Let $S$ be the set of all positive integers which are one more than a multiple of $5$.

```{dropdown} Solution

(i) $P = \{ x \in \mathbb{N}\ |\ 2 \leq x \leq 16\} ( = \{ 2, 3, \ldots, 16\})$

(ii) $Q = \{ x \in \mathbb{N}\ |\ \frac{x}{3} \in \mathbb{N} \}$

(iii) $R = \{ x \in \mathbb{N}\ |\ x = 2k, k \in \mathbb{N}\}$

(iv) $S = \{ x \in \mathbb{N}\ |\ x = 5k+1, k \in \mathbb{N}\}$

```

## Some well-known sets

- **The natural numbers, $\mathbb{N}$**

A natural number is a positive whole number.

$$ \mathbb{N} = \{ 1,2,3,4, \ldots \}$$

Note: some definitions of $\mathbb{N}$ include zero; it can be useful to clarify which you mean. We use the term 'positive integers' to mean $\{1,2,3, \ldots \}$ and 'non-negative integers' or sometimes 'whole numbers' to mean $\{0,1,2,3, \ldots\}$ (which is also occasionally denoted $\mathbb{N}_0$).

- **The integers, $\mathbb{Z}$**

The integers are the positive and negative whole numbers, including zero:

$$ \mathbb{Z} = \{ \ldots, -3, -2, -1, 0, 1, 2, 3, \ldots \} $$

We can also define the positive and negative integers:

$$ \mathbb{Z}^+ = \mathbb{N} = \{ 1, 2, 3, \ldots \} \qquad \mathbb{Z}^- =\{ -1, -2, -3, \ldots \}$$

- **The rational numbers, $\mathbb{Q}$**

A rational number is a ratio of two integers in the form $\frac{p}{q}$ where $q \neq 0$.

$$ \mathbb{Q} = \{ x\ |\ x = \frac{p}{q}, p,q \in \mathbb{Z}, q\neq 0\} $$

- **The irrational numbers, $\mathbb{Q}'$**

An irrational number is a real number which cannot be written as a ratio of two integers $\frac{p}{q}$.

$$ \mathbb{Q}' = \mathbb{R}\setminus \mathbb{Q}= \{ x\ |\ x \neq \frac{p}{q}, p,q \in \mathbb{Z}\} $$

- **The real numbers, $\mathbb{R}$**

Real numbers are the collection of all rational and irrational numbers.

$$\mathbb{R} = \mathbb{Q} \cup \mathbb{Q}' = \{ x\ |\ -\infty < x < \infty \} $$

We can also define the positive and negative real numbers:

$$ \mathbb{R}^+ = \{ x \in \mathbb{R}\ |\ x > 0\} \qquad \mathbb{R}^- =\{  x \in \mathbb{R} | x < 0\}$$

- **The complex numbers, $\mathbb{C}$**

Complex numbers are numbers of the form $z =a + ib$ where $a$ and $b$ are real numbers and $i$ is the imaginary unit $\sqrt{-1}$.

$$\mathbb{R} = \{ z = a +ib\ |\ a,b \in \mathbb{R} \}$$

:class: important

## Intervals

Many useful examples of sets can be defined as chunks of $\mathbb{R}$ - usually, the set of numbers between a pair of given endpoints.

```{admonition} Definition 1.2 - Interval
:label: interval-definition

An **interval** of the real line is a finite section of $\mathbb{R}$ defined in terms of its endpoints. Intervals can be open or closed, depending on whether they include or exclude their endpoints.

- Closed interval: $[a,b] = \{ x \in \mathbb{R}\ |\ a \leq x \leq b \}$
- Open interval: $(a,b) = \{ x \in \mathbb{R}\ |\ a < x < b \}$
- Half-open interval: $[a,b) = \{ x \in \mathbb{R}\ |\ a \leq x < b \}$
or $(a,b] = \{ x \in \mathbb{R}\ |\ a < x \leq b \}$

A square bracket at an endpoint indicates it is included in the set, whereas a parenthesis (round bracket) indicates it is
not included.

```

````{admonition} Example 1.3
:label: interval-notation-example
:class: hint

Write the following intervals as a set of inequalities on $x$.

(i) $[2,4]$

(ii) $(0.5,0.75]$

(iii) $(c,d)$

Write the following inequalities as intervals of $\mathbb{R}$. 

(iv) $A = \{ x \in \mathbb{R}\ |\ 1 \leq x < 4 \}$

(v) $B = \{ x \in \mathbb{R}\ |\ 20 \geq x \geq 18 \}$

(vi) $C = \{ x \in \mathbb{R}\ |\ 0.2 < x < 0.3 \}$

```{dropdown} Solution

(i) $[2,4] = \{ x \in \mathbb{R}\ |\ 2 \leq x \leq 4 \}$

(ii) $(0.5,0.75] = \{ x \in \mathbb{R}\ |\ 0.5 < x \leq 0.75 \}$

(iii) $(c,d) = \{ x \in \mathbb{R}\ |\ c < x < d \}$

(iv) $[1,4)$

(v) $[18,20]$

(vi) $(0.2,0.3)$

```
