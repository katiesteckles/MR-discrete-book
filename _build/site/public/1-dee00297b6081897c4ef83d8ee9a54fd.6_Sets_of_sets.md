# Sets of sets

Once we have the notion of as set, we can construct different kinds of sets - including sets which contain other sets, and use them to describe structures in mathematics. For example, if we consider a set of lines, each element is itself a set of points.

We can write
$$\textrm{The elements of the set }\{\{2, 3\}, \{2\}, \{5, 6\}\} \textrm{ are the sets } \{2, 3\}, \{2\} \textrm{ and } \{5, 6\}$$

```{admonition} Note
:class: important

Remember that the notation $\{a\}$ means 'the set containing the element $a$'. The notation $\{ \{a\}\}$ means 'the set containing the set containing the element $a$'.

```

````{admonition} Example 1.12
:label: sets-of-sets-example
:class: hint

(ii) Is $\{1, 2\} \in \{\{1, 2\}, \{1, 3, 4\}\}$?

(i) Yes (see above).
````

## Power sets


```{admonition} Definition 1.8 - Power set
:label: power-set-definition

The **power set** of a set $A$ is the set of all possible subsets of $A$ (including the set itself, and the empty set). The power set of $A$ is denoted by $P(A)$.

$$P(A) = \{x\ |\ x \subseteq A\}$$

If $A$ is a finite set and has $k$ elements, then $P(A)$ will have $2^k$ elements.

$$n(A) = k \quad \Rightarrow \quad n(P(A)) = 2^k$$

```

For example: Let $A=\{a, b, c\}$. Then $P(A)=\{\varnothing, \{a\},\{b\}, \{c\}, \{a, b\}, \{a, c\}, \{b, c\}, A\}$

````{admonition} Example 1.13
:label: power-sets-example
:class: hint

(i)  Let $A = \{ h, k \}$. Write down $P(A)$ and $n(P(A))$.

(ii)  Let $B = \{ 1, 2, 3, 4 \}$. Write down $P(B)$ and $n(P(B))$.

(iii) What is the power set of the empty set $\varnothing$?

(iv) What is the power set of $\{\varnothing\}$?

```{dropdown} Solution

(i) $P(A) = \{ \varnothing, \{1\}, \{2\}, A\}$, which contains $2^2$ = 4 elements. 

(ii) $P(B) = \{ \varnothing, \{1\}, \{2\}, \{3\}, \{4\}, \{1,2\}, \{1,3\}, \{1,4\}, \{2,3\}, \{2,4\}, \{3,4\}, \{1,2,3\}, \{1,2,4\}, \{1,3,4\}, \{2,3,4\}, B\}$, which contains $2^4$ = 16 elements. 

(iii) The empty set has exactly one subset, namely, itself. So, $P(\varnothing) = \{\varnothing\}$, and $n(P(\varnothing))=2^0=1$.

(iv) The set $\{\varnothing\}$ has exactly two subsets, namely, $\varnothing$ and the set $\{\varnothing\}$ itself. Therefore
$P(\{\varnothing\})=\{ \varnothing, \{\varnothing\}\}$ and $n(P(\{\varnothing)\})=2^1=2$.

```
````
