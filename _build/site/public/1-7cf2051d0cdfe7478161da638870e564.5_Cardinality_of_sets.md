# Cardinality of sets

1.7 Finite and Countable Sets
Sets can be finite or infinite. A set is finite if it is an empty or if it consists of exactly n distinct
elements where n is a positive integer; otherwise it is infinite.
Example 1
Let M be the set of the days of the week; that is,
M = {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday}
Then M is finite.
Example 2
Let P = {x | x is a river on the earth}.
Although it may difficult to count the number of rivers on the earth, P is a finite set.
Example 3
Let Y be the set of (positive) even integers, i.e. Y = {2, 4, 6, ……}.
Then Y is an infinite set.
Example 4
Let I be the unit interval of real numbers, i.e. I = {𝑥|0 ≤ 𝑥 ≤ 1}.
Then I is also an infinite set.
Example 5
The sets of Natural Numbers, N, Integer numbers, Z, Rational numbers, Q, Irrational numbers, I,
and Real numbers, R, are infinite sets.
A set S is countable if it is finite or if its elements of S can be arranged in the form of a
sequence, in which case S is said to be countable infinite; otherwise the set is uncountable.
The set in the example 3 is countable infinite, whereas it can be shown that the set in the example
4 is uncountable.

1.8. Set Cardinality
The cardinality of a finite set A is the number of elements that it contains. Cardinality is
denoted by n(A) or |𝐴| (i.e. the number of elements in a finite set A).
Remark: The term cardinality comes from the common usage of the term cardinal
number as the size of a finite set.
Example: Let A be the set of odd positive integers less than 10. Then n(A)=|A| = 5.
Example: Let S be the set of letters in the English alphabet. Then n(S)=|S| = 26.
Example: Because the null set has no elements, it follows that n(∅)= |∅ | = 0.
Note the following cardinality for the combination of sets:
If A and B are finite disjoint sets. Then 𝐴 ∪ 𝐵 is finite and
𝑛(𝐴 ∪ 𝐵) = 𝑛(𝐴) + 𝑛(𝐵).
If A be a subset of a finite universal set U, then U is the disjoint union of A and its
complement𝐴𝐶 .Thus according to above
𝑛(𝑈) = 𝑛(𝐴) + 𝑛(𝐴𝐶)
If A be a subset of a finite universal set U. Then
𝑛(𝐴𝐶) = 𝑛(𝑈) − 𝑛(𝐴)
Example: if there are 20 male students in a class of 35 students,
then there is 35 – 20 = 15 female students.
If A and B are finite sets. Then
𝑛(𝐴\𝐵) = 𝑛(𝐴) − 𝑛(𝐴 ∩ 𝐵)
Example: suppose an archery class A contains 35 students, and 15 of them are also in a
bowling class B. Then
𝑛(𝐴\𝐵) = 𝑛(𝐴) − 𝑛(𝐴 ∩ 𝐵) = 35 – 15 = 20

( Inclusion-Exclusion Principal)
Suppose A and B are finite sets, not necessarily disjoint. Then 𝐴 ∩ 𝐵 and 𝐴 ∪ 𝐵 are
finite, and
𝑛(𝐴 ∪ 𝐵) = 𝑛(𝐴) + 𝑛(𝐵) − 𝑛(𝐴 ∩ 𝐵).
That is, we find the number of elements in A or B (or both) by first adding 𝑛(𝐴) and 𝑛(𝐵)
(inclusion) and then subtracting 𝑛(𝐴 ∩ 𝐵) (exclusion) since the elements in 𝐴 ∩ 𝐵were
counted twice.
Suppose A, B and C are finite sets. Then 𝐴 ∪ 𝐵 ∪ 𝐶 is finite and
𝑛(𝐴 ∪ 𝐵 ∪ 𝐶) = 𝑛(𝐴) + 𝑛(𝐵) + 𝑛(𝐶) − 𝑛(𝐴 ∩ 𝐵) − 𝑛(𝐴 ∩ 𝐶) − 𝑛(𝐵 ∩ 𝐶) + 𝑛(𝐴 ∩ 𝐵 ∩ 𝐶).
Example
Suppose an art class A has 25 students and 10 of them are taking a biology class B. Then
the number of students in class A which are not in class B is:
𝑛(𝐴\𝐵) = 𝑛(𝐴) − 𝑛(𝐴 ∩ 𝐵) = 25 − 10 = 15
