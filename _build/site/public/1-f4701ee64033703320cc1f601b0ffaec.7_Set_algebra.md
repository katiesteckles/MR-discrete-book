1 𝐴 ∩ 𝐵 = 𝐴 2. 𝐴 ∪ 𝐵 = 𝐵 3. 𝐵𝐶 ⊂ 𝐴𝐶
4.𝐴 ∩ 𝐵𝐶 = 𝜑 5. 𝐵 ∪ 𝐴𝐶 = 𝑈
