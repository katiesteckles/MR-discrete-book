# Relations


3.0 Introduction
Relations and its types concepts are one of the important topics of set theory.
Sets, relations and functions all three are interlinked topics. Sets denote the collection of
ordered elements whereas relations and functions define the operations performed on
sets.
A relation defines the connection between the two given sets. Also, there are types of
relations stating the connections between the sets. Hence, here we will learn about
relations and its types in detail.
3.1 Definition: Relation
A relation in mathematics defines the relationship between two different sets of
information. If two sets are considered, the relation between them will be established if
there is a connection between the elements of two or more non-empty sets.
Therefore, we can say,
‘A set of ordered pairs is defined as a relation “R” .’
So, a binary relation R from a set A to a set B is a subset of the cartesian product between
the sets A and B (A × B). (i.e. R ⊂ A × B). If (a,b)∈ A × B we write aRb.
The set Dom (R)={a∈A |(a,b) ∈R for some b∈B} is called the domain of R .
The set Range (R)={b∈B |(a,b) ∈R for some a∈A} is called the range of R .

3.1.1 Types of Relations
There are 9 main types of relations which include:
• Reflexive Relation
In a reflexive relation on a set A, every element map to itself.
i.e. the reflexive relation is given by (a, a) ∈ R for all a∈ A (i.e. ∀ a∈ A)
For example, consider a set A = {1, 2,3,4}.
Now an example of reflexive relation will be
R = {(1, 1), (2, 2), (3, 3), (4, 4)}.
An example for a reflexive relation:
(a) (∀ x ∈ ℝ (Real numbers)) (x = x). (Equality is a reflexive relation).
(b) (∀ x ∈ ℝ) (x < x). (Less than is not a reflexive relation).
(c) (∀ x ∈ ℝ) (x ≥ x). (Greater than or equal is a reflexive relation).
(d) (∀ a ∈ N) (a | a). (Divides is a reflexive relation).
• Irreflexive Relation
Irreflexive is given by (a, a) ∉ R for all a∈ A (i.e. ∀ a∈ A)
An example for irreflexive (not a reflexive) relation:
(∀ x ∈ ℝ) (x ≠ x). (Not equal is not a reflexive relation).
• Symmetric Relation
In a symmetric relation on a set A, if a R b is true then b R a is also true. In other words,
a relation R on a set A is symmetric only if (b, a) ∈ R is true when (a, b) ∈ R.
i.e. for a symmetric relation on a set A, a R b ⇒ b R a, for all a, b ∈ A (i.e.∀ a, b ∈ A)
Example: Let A = {1, 2, 3} and R = {(1, 1), (2, 2), (1, 2), (2, 1), (2, 3), (3, 2)}
Solution: The relation R is symmetric as for every (a, b) ∈ R, we have (b, a) ∈ R,
i.e., (1, 2), (2, 1), (2, 3), (3, 2) ∈ R
An example of symmetric relations:
(∀ x, y ∈ ℝ) ((x = y) → (y = x)) (Equality is symmetric).

• Anti-Symmetric Relation
A relation R on a set A is said to be anti-symmetric relation,
if (a, b) ∈ R and (b, a) ∈ R ⇒ a = b, ∀ a, b ∈ A
Example: Let A = {1, 2, 3} and R = {(1, 1), (2, 2)}.
Is the relation R antisymmetric?
Solution:
The relation R is antisymmetric as a = b when (a, b) and (b, a) both belong to R.
An example for Anti-Symmetric relations:
(a)(∀ x, y ∈ ℝ)(((x = y) ∧ (y = x)) ⇒ (x = y)), (Equality is anti-symmetric).
(b) (∀ x, y ∈ ℝ) ((x < y ∧ y < x) ⇒ (x = y)), (Less than is anti-symmetric).
(c) (∀ x, y ∈ ℝ) (x ≥ y ∧ y ≥ x ⇒ x = y), (Greater than is anti-symmetric).
(d) (∀ a, b ∈ N) (a | b ∧ b | a ⇒ a = b), (Divides is anti-symmetric).
An example for not antisymmetric
(∀ x, y ∈ ℝ) ((x ≠ y ∧ y ≠ x) ⇒ (x = y)).( Not equal is not anti-symmetric)
Example: Let A = {4, 5, 6} and R = {(4, 4), (4, 5), (5, 4), (5, 6), (4, 6)}.
Is the relation R antisymmetric?

The relation R is not antisymmetric as 4 ≠ 5 but (4, 5) and (5, 4) both belong to R.

• Transitive Relation
A relation R on a set A is called transitive if (a, b) ∈ R, (b, c) ∈ R, then (a, c) ∈ R, for all
a, b, c ∈ A.
i.e. R is a transitive relation on a set A, a R b and b R c ⇒ a R c ∀ a, b, c ∈ A
Example: Let A = {1, 2, 3} and R = {(1, 2), (2, 1), (1, 1), (2, 2)}.
Is the relation R transitive?
Solution: The relation R is transitive as for every (a, b) and (b, c) ∈R, we have
(a, c) ∈ R i.e. (1, 2) and (2, 1) ∈ R ⇒ (1, 1) ∈ R
An example for Transitive relation:
(a) (∀ x, y, z ∈ ℝ) (((x = y) ∧ (y = z)) → (x = z)). (Equality is transitive)
(b) (∀ x, y, z ∈ ℝ) ((x < y ∧ y < z) → (x < z)). (Less than is transitive).
(c) (∀ x, y, z ∈ ℝ) (x ≥ y ∧ y ≥ z → x ≥ z). (Greater than or equal is transitive).
(d) (∀ a, b, c ∈ N) (a | b ∧ b | c → a | c). (Divides is transitive).
An example for non-Transitive relation:
(∀ x, y, z ∈ R) ((x ≠ y ∧ y ≠ z) → (x ≠ z)). (Not equal is not transitive).
Note:
(a) ⊥r is not transitive since a ⊥r b, b ⊥r c then it is not true that a ⊥r c.
(b) Since no line is ∥ to itself, we can have a ∥ b, b ∥ a but a ∦ a.
Thus ∥ is not transitive, but it will be transitive in the plane.
• Equivalence Relation
A relation R on a set A is called an equivalence relation, if it is simultaneously reflexive,
symmetric and transitive on A.
Example: The relation “is equal to”, denoted “=”, is an equivalence relation on the set of
real numbers since for any x, y, z ∈ R:
1. (Reflexivity) x = x,
2. (Symmetry) if x = y then y = x,
3. (Transitivity) if x = y and y = z then x = z.
All of these are true.

In an identity relation, every element of a set is related to itself only.
i.e. For identity relation, IA = {(a, a), a ∈ A}
For example, in a set A = {a, b, c}, the identity relation will be IA = {a, a}, {b, b}, {c, c}.
Identity relation IA on set A is reflexive, transitive and symmetric. So identity relation IA
is an Equivalence Relation.

• Inverse Relation
If A and B are two non-empty sets and R be a relation from A to B, such that
R = {(a, b) : a ∈ A, b ∈ B}, then the inverse of R, denoted by R-1, is a relation from B to A
and is defined by R-1 = {(b, a): (a, b) ∈ R}
For example, if set A = {(a, b), (c, d)}, then inverse relation will be R-1 = {(b, a), (d, c)}.

• Composition of Relation
Let R and S be two relations from sets A to B and B to C respectively, then we can define relation
S o R from A to C such that (a, c) ∈ S o R ⇔ ∃ b ∈ B such that (a, b) ∈ R and (b, c) ∈ S.
This relation S o R is called the composition of R and S.
Example:
Consider the sets A={a,b}, B={0,1,2}, and C={x,y}.
The relation R between sets A and B is given by R={(a,0),(a,2),(b,1)}.
The relation S between sets B and C is defined as
S={(0,x),(0,y),(1,y),(2,y)}.
The composition of relations S∘ R is written as
S∘ R={(a,x),(a,y),(b,y)}.

• Partial Order Relation
Definition: A relation ≤ on a set A is called a partial order if ≤ is reflexive, antisymmetric, and
transitive. In this case we call A a poset.
Example:
Show that the set ℤ of integers together with the relation of inequality ≤ is a poset.
Solution:
1. 2. 3. ≤ is reflexive: For all x ∈ ℤ we have x ≤ x since x = x.
≤ is antisymmetric: By the law of real numbers, for a given pair of numbers x and
y only one of the following is true: x < y, x = y, or x > y.
So if x ≤ y and y ≤ x then we must have x = y.
≤ is transitive: By the transitivity property of < in Real numbers (R)
if x < y and y < z then x < z.
Thus, if x ≤ y and y ≤ z then the definition of ≤ and the above property imply that
x ≤ z.
Example:
Show that the relation a|b in Natural numbers (N) is a partial order relation.
Solution:
a) b) c) Reflexivity: Since a = 1 · a, we have a|a.
Antisymmetry: Suppose that a|b and b|a. Then there exist positive integers k1 and k2
such that b = k1.a and a = k2 .b. Hence, a = k1 k2.a which implies that k1 k2 = 1.
Since k1 k2∈ N , we must have k1 = k2 = 1; that is, a = b.
Transitivity: Suppose that a|b and b|c. Then there exist positive integers k1 and k2
such that b = k1.a and c = k2 .b. Thus, c = k1 k2 a which means that a|c.

Definition: if A is a poset then we say that a and b are comparable if either a ≤ b or b ≤ a.
If every pair of elements of A are comparable then we call ≤ a total order relation.

Important Results on Relation
• If R and S are two equivalence relations on a set A, then R ∩ S is also on ‘equivalence relation
on A.
• The union 𝑅 ∪S of two equivalence relations on a set is not necessarily an equivalence relation
on the set.
• If R is an equivalence relation on a set A, then R-1 is also an equivalence relation on A.
