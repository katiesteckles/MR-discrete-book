# Relations between sets

```{admonition} Definition 1.3 - Subset
:label: subset-definition

A **subset** is a set whose elements are contained in a larger set. We say $A$ is a subset of $B$, denoted $A \subseteq B$, if every element of $A$ is also an element in $B$.

$$ A \subseteq B\quad \Leftrightarrow\quad x \in A \Rightarrow x \in B\quad \Leftrightarrow\quad B \supseteq A$$

We can also say that $B$ is a superset of $A$.

If $A$ is not a subset of $B$ - that is, there is at least one element of $A$ which does not belong to $B$ - then we write $A \not\subseteq B$.

A **proper subset** is a subset which is not equal to the larger set - we write $A \subset B$, or say '$A$ is properly contained in $B$', if there is at least one element of $B$ not in $A$.

$$ A \subset B\quad \Leftrightarrow\quad x \in A \Rightarrow x \in B, A \neq B$$

```

```{admonition} Note
:class: important

This notation follows the same rule as the $<, >, \leq, \geq$ symbols we use for 'less than' versus 'less than or equal to', etc. The second line under the symbol mimics the $=$ symbol.
```

For example,

- $P = \{x\}, T = \{x, y, z\}$ and $M = \{v, w, x, y, z\}$ are all subsets of $L = \{v, w, x, y, z\}$, and $P$ and $T$ are proper subsets. Therefore, we may write $P \subset L, T\subset L$ and $M\subseteq L$.
- $S_1 = \{1,2,3\}$ and $S_2 = \{1,2\}$. Then $S_2 \subseteq S_1$ but $S_1 \not\subset S_2$.
- $\mathbb{N} \subset \mathbb{Z}$, since every natural number is also an integer. Also, $\mathbb{Z} \subset \mathbb{Q}$, since every integer number is also a rational number (e.g. $3 = \frac{3}{1}$), and $\mathbb{Q}
 \subset \mathbb{R}$, since every rational number is also a real number.

````{admonition} Theorem 1.1 - Properties of subsets
:label: properties-of-subsets-theorem
:class: attention

- For any set $A$, we have $A \subseteq A$.
- If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$.

````

## Some specific sets

```{admonition} Definition 1.4 - The universal set
:label: universal-set-definition

The **universal set**, denoted by $U$, is a set containing all  is a set containing all the elements of all sets under consideration. For example, if we are working with sets of real numbers, $U = \mathbb{R}$.

```

- If we are studying human populations, the universal set consists of all the people in the world.
- In plane geometry, the universal set consists of all points in the plane.
- We could define $U$ to be the set of whole numbers from 1 to 10 (i.e. $U=\{1, 2, 3, \cdots
9, 10\}$), and then only consider sets which are subsets of $U$.

```{admonition} Definition 1.5 - The empty set
:label: empty-set-definition

The **empty set**, sometimes also called the **null set**, is a set containing no elements. It can be denoted by $\{\}$ or $\varnothing$.

```

For example,
$$ \{x\ |\ x \in \mathbb{N}, x < 0\} = \varnothing$$

```{admonition} Definition 1.6 - Unit set
:label: unit-set-definition

A **unit set** is a set containing only a single element. For example, $S = \{x\}$.

```

```{admonition} Note
:class: important

Note that $x$, the element, is distinct from $\{x\}$, the set containing only the element $x$. To denote a unit set, we write $S = \{x\}$, not $S = x$.

```

````{admonition} Theorem 1.2 - Properties of the universal and empty sets
:label: properties-of-universal-and-empty-sets-theorem
:class: attention

- $\varnothing$ is a subset of every set $A$, and a proper subset of every set $A \neq \varnothing$.
- For any set $A$, we have $\varnothing \subseteq A \subseteq U$.

````

## Set equality

```{admonition} Definition 1.7 - Set equality
:label: set-equality-definition

Two sets A and B are **equal** (denoted $A=B$), if and only if they have exactly the same elements. That is, each member of $A$ is a member of $B$, and vice versa.

$$ A = B\quad \Leftrightarrow\quad A \subseteq B, B \subseteq A$$

```

For example,
- $\{ \textrm{Prolog, Lisp, Modula2, Java, C}\} = \{\textrm{Lisp, Modula2, C, Prolog, Java}\}$
- $\{3, 6, 9, 12, \ldots\}=\{x \in \mathbb{Z}, x=3m, m>0 \in \mathbb{Z}\}$.
- $\{x \in A\ |\ x\textrm{ is a vowel}\} = \{a, e, i, o, u\}$
- $\{2, 3, 4\} = \{x\ |\ x\textrm{ is a digit in the numeral } 23432\}$

```{admonition} Theorem 1.3 - Properties of set equality
:label: properties-of-set-equality-theorem
:class: attention

- For any set $A$, $A = A$.
- If $A = B$, then $B = A$
- If $A = B$ and $B = C$, then $A = C$. 
- $A = B \Leftrightarrow A \subseteq B$ and $B \subseteq A$.

```

## Set Complements and differences

```{admonition} Definition 1.8 - Set complement
:label: set-complement-definition

The **complement** of a set $A$, denoted by $A^C$ or $A'$, is the set of all elements under discussion that are not in the set $A$. In set-builder notation, $A^\mathsf{c}$ can be expressed as
$$A^\mathsf{c} = \{x\ |\ x \in U, x \not\in A\}$$

```

For example,
- Let $U = \mathbb{R}$, the set of all real numbers. If A is the set of negative real numbers including zero (i.e. $A = \{ x | -\infty <x \leq 0\}$), then $A^\mathsf{c}$ is the set of positive real numbers
(i.e. $A^\mathsf{c} = \{ x | 0 < x < \infty\}$).
- Let $U = \mathbb{Z}^+$, the set of all positive integers. If $A$ is the set of even
integers including zero (i.e. $A=\{0, 2, 4, 6, \ldots\}$), then $A^\mathsf{c}$ is the set of odd integers
(i.e. $A^\mathsf{c} = \{3, 5, 7, \cdots \}$).
- Let $U$ be the set of students at a university, and let $C$ and $N$ denote, respectively, the
commuting and non-commuting students in $U$. Then
$$ C^\mathsf{c} = N \textrm{ and } N^\mathsf{c} = C$$


```{admonition} Definition 1.9 - Set difference
:label: set-difference-definition

The **difference of two sets** $A$ and $B$, also called the relative complement of $B$ with respect to $A$, denoted by $A\setminus B$, is the set of elements which belong to $A$ but which do not belong
to $B$; that is:
$$ A \setminus B = \{ x\ |\ x \in A, x \not\in B \}$$
 The set $A\setminus B$ can be read as “A minus B”. Some texts denote $A \setminus B$ by $A - B$.

```

For example, consider the sets $A=\{1, 2, 3,4\}$, $B=\{3, 4, 5, 6, 7\}$ and $C=\{6, 7, 8, 9\}$. Then
$$ A\setminus B=\{1, 2\} \qquad B\setminus C =\{3, 4, 5 \}$$
$$ B\setminus A =\{5, 6, 7\} \qquad C\setminus B =\{8, 9\}$$
