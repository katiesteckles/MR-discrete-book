# Venn Diagrams

```{figure} ../_images/venn-plaque.png
:width: 450
:align: center
:alt: Photo showing a plaque on a wall, which is made from two overlapping circles labelled 'Mathematician, philosopher and Anglican priest' and 'Really strong beard game'. The region in the middle is labelled 'JOHN VENN'.
```
Named after 19th-century mathematician John Venn, **Venn diagrams** are an extremely useful way to visualise sets and their properties and relations.

For small numbers of sets, it is possible to construct Venn diagrams entirely using circles or ellipses, but larger numbers are possible using more complicated shapes.

```{figure} ../_images/venn-rectangle.png
:width: 250
:class: dark:hidden
:align: center
:alt: Empty Venn diagram made from just a rectangle
```
```{figure} ../_images/venn-rectangle-w.png
:width: 250
:class: hidden dark:block
:align: center
:alt: Empty Venn diagram made from just a rectangle
```


All Venn diagrams are enclose in a rectangle which represents the universal set $U$ - all the points inside the rectangle are in $U$.

Defined subsets of $U$ are represented by a circle or ellipse drawn inside the rectangle.

```{figure} ../_images/venn-a.png
:width: 250
:class: dark:hidden
:align: center
:alt: Venn diagram showing a single set and its complement
```
```{figure} ../_images/venn-a-w.png
:width: 250
:class: hidden dark:block
:align: center
:alt: Venn diagram showing a single set and its complement
```

Here we can see the set $A$, represented by the points inside the rectangle, and the complement of $A$ ($A^\mathsf{c} = U \setminus A$).

If we have multiple subsets within $U$, they are drawn as overlapping, so we can define the set of points that lie in both sets, and have a region to represent it. The regions can be labelled inside the circle, or outside just next to the line (as long as it's clear what you mean).

As an alternative to Venn diagrams, we use the term **Euler diagram** to describe a diagram where not all overlaps are present. This may be desirable, especially if some are empty, or if including them all would make the diagram too complicated. The four-set example above made from circles is an example of an Euler diagram.

Euler diagrams have a little more flexibility - for example, if one set is a proper subset of another, its circle can be drawn inside another set.

As we develop more terminology to describe sets and their relationships, we will be able to use Venn diagrams to illustrate them and to help us make sense of how the sets are related.
