# Set Algebra

Much like we can manipulate other mathematical objects like numbers, we can combine and modify sets as a form of algebra, which we call **set algebra**.

```{admonition} Theorem 1.8 - Duality of set equations
:label: duality-of-set-equations-theorem
:class: attention

Let $E$ be an equation in set algebra. TThe dual $E*$ of $E$ is the equation obtained by replacing each occurrence of $\cup$ with $\cap$ and vice versa, and each occurrence of $U$ with $\varnothing$ and vice versa.

If $E$ is a true statement about sets, then its dual $E*$ is also true.

```

For example, we know $(U \cap A) \cup (B \cap A) = A$. By duality, we also know that $(\varnothing \cup A) \cap (B \cup A) = A$

## Laws of Set Algebra

The following properties and relationships hold for set operations.

\textbf{Complement laws:}
$$ A \cup A^\mathsf{c} = U \qquad  A \cap A^\mathsf{c} = \varnothing$$

\textbf{Identity laws:}
$$ A \cap U = A \qquad A cup \varnothing = A$$

\textbf{Domination laws:}
$$A \cup U = U \qquad A \cap \varnothing = \varnothing$$

\textbf{Idempotent laws:}
$$A \cup A = A \qquad A \cap A = \varnothing$$

\textbf{Double complement law:}
$$(A^\mathsf{c})^\mathsf{c} = A$$

\textbf{Commutative laws:}
$$A \cup B = B \cup A \qquad A \cap B = B \cap A$$

\textbf{Absorption laws:}
$$A \cup (A \cap B) = A \qquad A \cap (A \cup B) = A$$

\textbf{Associative laws:}
$$(A \cup B) \cup C = A \cup (B \cup C) = A \cup B \cup C$$
$$(A \cap B) \cap C = A \cap (B \cap C) = A \cap B \cap C$$

\textbf{Distributive laws:}
$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C) \qquad A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
$$A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C) \qquad A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)$$

\textbf{De Morgan’s laws:}
$$(A \cup B)^\mathsf{c} = A^\mathsf{c} \cap B^\mathsf{c} \qquad (A \cap B)^\mathsf{c} = A^\mathsf{c} \cup B^\mathsf{c} $$

```{admonition} Theorem 1.9 
:label: equivalent-statements-about-sets-theorem
:class: attention

Each of the following conditions is equivalent to $A \subset B$:

- $A \cap B = A$
- $A \cup B = B$
- $B^\mathsf{c} \subset A^\mathsf{c}$
- $A \cap B^\mathsf{c} = \varnothing$
- $B \cup A^\mathsf{c} = U$
```
